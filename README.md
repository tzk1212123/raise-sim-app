# RAISE simulator: browser demo

Live site: https://tzk1212123.github.io/raise-sim-app/

A simulator of the RAISE SDS 94% + Tween 20 contact-angle experiment (target 72°, minimise surfactant)
with a comparison of experiment-planning methods (Random, OFAT, Bayesian optimisation).
The Python simulator runs in your browser through [Pyodide](https://pyodide.org); the first load takes 20–60 s.
LLM-agent contestants need API keys and run only in the local version.

This repository holds the built site only and is regenerated automatically.
