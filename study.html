How to read

  • Each repeat uses one seed for all contestants: same world, same starters, same noise. Differences come from decisions.
  • Success = the final answer's true angle is on target (70.4–73.6°). Bracket = 95% interval.
  • Score = 100 × desirability of the answer if on target, else 0. Best possible ≈ 97.
  • Tests to good = first test that measured on target with score ≥ 90.
  • If two intervals overlap a lot, the difference may be luck. Add repeats.
